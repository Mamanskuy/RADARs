RADARs adalah aplikasi web berbasis Laravel yang dibuat untuk Dinas Kearsipan dan Perpustakaan (Arpus) Kota Semarang guna mengelola arsip dokumen digital per lembaga/instansi, di mana admin dapat menambah/menghapus lembaga serta memantau seluruh data arsip lintas lembaga, sementara user dapat menginput, mengedit, menghapus, dan mengekspor data arsip per lembaga beserta riwayat perubahannya.
